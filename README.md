# QuickMeeting

QuickMeeting is a macOS app that records your meetings automatically or on demand, then turns them into transcripts on your Mac. It keeps each meeting’s recording and transcript together in a local library, so you can review conversations later without relying on a cloud transcription service.

## Automatic recording

Turn on Auto-recording in Settings and choose the meeting apps QuickMeeting should watch. It will start and stop recording based on activity in those apps, so you can focus on the conversation instead of remembering to press Record.

## How to use it

1. Start a recording from the app or the menu bar.
2. Stop the recording when the meeting is finished.
3. Open the meeting and start transcription.
4. Review the transcript, play back the audio, and make any corrections you need.

You can also rename meetings and speakers, generate a meeting summary, and copy the transcript as Markdown for use in another app. Optional calendar integration can add context from your upcoming meetings.
